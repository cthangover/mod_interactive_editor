# Редактор интерактивов — кликабельные объекты на фоне сцены

Редактор интерактивов правит кликабельные объекты `interactive_base` — двери, сундуки, лампы, невидимые активные зоны — прямо поверх фона, которому они принадлежат. Коллайдер каждого объекта ставится и меняет форму мышью, а спрайт, слой, курсор и команды по клику задаются в полях.

## Как открыть

Кнопка с молотком на игровом тулбаре → **Редактор интерактивов**.

## Правка объектов

![Редактор интерактивов с файлом graveyard_interactives.json мода cthangover_game: объекты crypt_spot и book_wipe, выбран прямоугольный коллайдер crypt_spot с ручками, справа свойства: слой foreground, курсор PointingHand, коллайдер, подсветка и действие-сценарий.](assets/interactive-editor.jpg)

1. Выберите мод и файл интерактивов (`interactives/*.json`). **Объекты файла** перечисляют его объекты; **+ Новый**, **Дублировать** и **Удалить объект** меняют список.
2. Превью показывает фон сцены, чей сценарий добавляет объект (редактор ищет это по сценариям); **Фон превью** выбирает другой.
3. Щёлкните коллайдер, чтобы выбрать его, и тяните ручки. **Форма** — прямоугольник, круг или полигон; в режиме полигона щелчок по фону добавляет вершину, ПКМ по вершине удаляет её (не меньше трёх вершин).
4. **Свойства**: **ID**, **Текстура** (пусто — невидимая кликабельная зона), **Слой**, **Z-порядок**, **Курсор**, **Активен**, **Видим** и **Команды по клику (по одной в строке)**. **Подсветка** (**Цвет**, **Масштаб**) задаёт, как объект светится и увеличивается под курсором. В **Действиях** **Сценарий** — файл `.scenario`, который проигрывается по клику, а **Наведение** и **Уход** — команды, выполняемые, когда курсор входит на объект и уходит с него.
5. Ctrl+S сохраняет файл. Повторяющийся или пустой ID отклоняется с сообщением.

Сохранённый файл — обычные данные мода. Запущенная игра подхватывает его горячей перезагрузкой модов (сама после сохранения или по Ctrl+Shift+R), а объекты появляются, когда сценарий добавляет их в сцену.

## Зависимости

`tools_base`, `scenario_tools_base`, `interactive_base`, `ui_base`.
Старый пакет `editor_tools` ставит этот мод вместе с остальными авторскими окнами.
